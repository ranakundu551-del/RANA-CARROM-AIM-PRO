# RANA CARROM AIM PRO

A standalone Android carrom aiming practice board.

## Features
- Practice board with striker and target marker
- Drag the white striker to adjust your practice aim
- Displays the current aim angle

This app is a standalone practice simulator. It does not connect to, control, automate, or modify Carrom Pool or any online match.

## Build
GitHub Actions builds a debug APK when code is pushed to the main branch or when the workflow is run manually. Download it from the workflow run's Artifacts section.
